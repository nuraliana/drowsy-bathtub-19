One cat joke, one line, 110 characters. A bathtub mishap, a four-year grudge, and a camera — the punchline turns on the word "held" doing two jobs at once.

## Run it

```bash
python3 main.py
```

This writes the joke to `entry.txt` inside the directory set by `MAKEFUN_OUTPUT_DIR` (or `/output` by default). Nothing else goes in the file.

A tiny Python program that delivers the joke: a cat that tumbled into the bathtub once and has held a grudge ever since.
Built for the make.fun bounty "The One-Line Cat Joke That Lands" — one joke, one line, no more.
